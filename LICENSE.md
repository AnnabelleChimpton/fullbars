# Licences

Fullbars is three projects in one repository, each under its own licence. The full text is in each folder.

| Folder | What | Licence | Text |
|---|---|---|---|
| `android/` | The Android app | GPL-3.0-or-later | [android/LICENSE](android/LICENSE) |
| `server/` | The BRB server | Apache-2.0 | [server/LICENSE](server/LICENSE) |
| `srtla-kt/` | The SRTLA sender library | Apache-2.0 | [srtla-kt/LICENSE](srtla-kt/LICENSE) |

The server image builds BELABOX's `srtla_rec` unmodified from its own source and runs it as a separate program. It
is AGPL-3.0.

Code adapted or re-implemented from other projects, and their licences, are listed in
[THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md).
